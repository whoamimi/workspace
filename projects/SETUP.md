# Jupyter Notebook Remote Setup for Kaggle Competition

The following content contains steps for configuring remote accessing active Kernels on Kaggle website.

Kernel is defined as the interface between the hardware and software, managing system resources and processes.
Jupyter Notebooks runs as a small client–server system inside this operating system. By default, creating a new notebook from a Kaggle Project/Dataset/Hackathon creates a new containerized client server. In theory, you should be able to access the mounted data files in the notebook's environment through the hosted server.

Note, self-hosting notebook could put you at risk at cyber attacks if you are not savvy with web, networking or cybersecurity.

This setup method eliminates the common problems in:

- Downloading and caching large datasets for hackathons/competitions.
- Limited compute resources in local machines.

## Steps

1. Navigate to the Kaggle dataset site and create new notebook.
2. Enable Jupyter server's hosting service. Note, self-hosting notebooks could put you at risk of cyber attacks if and only if you are not savvy with web, networking or cybersecurity AKA Javascript.
