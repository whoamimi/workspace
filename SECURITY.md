# Security Policy

## Supported Versions

If you think you found a vulnerability, and even if you are not sure about it, please report it right away by sending an email to: mimi@whoamimis.blog with the subject line "Security: <short summary>".

I (the author, @whoamimi) will review it thoroughly and get back to you.

The following versions currently receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |
