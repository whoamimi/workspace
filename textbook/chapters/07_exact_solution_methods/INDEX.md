# 7.1: MDP

> **SYNTAX**
>   - Time (t)
>   - Action (A)
>   - State (S)
>   - Reward (R)
>
> **RL BASICS**
>   - Utility Function:
>       - Any function that is applying transformations (updates) to the agent's action or state.
>       - Returns a value that supports the agent's knowledge and decision making for its future steps. E.g. value functions, reward functions.
