# Mkdocs Site

Project managed with `uv` package manager and is deployed as static site on Github pages.

Theme setup

```bash
pip install mkdocs-terminal
```

## Dev Notes

- Installation & Setup Instructions: [Mkdocs Blog Setup Steps](https://vinhdata.com/blog/2026/01/29/how-to-setup-a-portfolio-website-with-mkdocs-and-github-actions/#prerequisites)
- To serve locally, run `uv run mkdocs serve`
